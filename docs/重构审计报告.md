## 三、重构断点

### 1. Controller 缺失 / 空壳

- **`behavior` Admin 控制器**：`AdminBehaviorController` 仅有类定义，无接口方法
  - 行为统计聚合接口未完成
  - 计数操作未加乐观锁（高并发丢计数风险）
  - 行为模块单元测试缺失
- **`file` 模块部分 Controller**：`FileAdminController`、`CollectController`、`FileController`、`MusicController`、`PictureController`、`QiniuController`、`ResourceAggregationController` 均无 `@Operation` 注解
- **`moment` Web Controller**：`MomentController` 无 `@Operation` 注解
- **`webInfo` Admin Controller**：`AdminWebInfoController` 无 `@Operation` 注解

### 2. Entity 命名不一致

- `im` 模块用 `entity/` 而其他模块统一用 `domain/pojo/`
- `im` 模块 Controller 用 `http/controller/` 而非标准 `controller/web/admin/`

## 六、优先级建议

| 优先级 | 任务 | 原因 |
|--------|------|------|
| **P0** | 执行 `fix_id_type_v2.sql` + `fix_is_del_v2.sql` | DB 类型不匹配会导致运行时错误 |

| **P3** | im 模块目录结构对齐 | 命名规范统一 |
| **P3** | `system` 空目录处理 | 初始化或移除 |
| **P3** | 行为模块单元测试 | 策略模式核心逻辑无测试保护 |
