## 二、重构断点

### 1. Service 层缺失

- `weblinks` 模块：6 个 Controller（Weblinks/Collect/Music/Picture/Qiniu/ResourceAggregation）全部没有 Service，违反分层规范

### 2. Controller 缺失

- `sysdict`：字典表管理没有 Controller 暴露接口
- `system`：空目录
- `family`：仅有 Admin Controller，缺 Web Controller
- `category`、`moment`、`tag`：仅有 Web Controller，缺 Admin 管理

### 3. Entity 命名不一致

- `im` 模块用 `entity/` 而其他模块统一用 `domain/pojo/`
- `im` 模块 Controller 用 `http/controller/` 而非标准 `controller/web/admin/`

### 4. 旧代码残留

- `ResourceCheckAspect` 是空壳实现

> **已清理项（2026-06-19 ~ 2026-06-21）：**
> - PoetryCache 注释残留已清理（0 处）
> - fastjson 新旧包名混用已解决（0 处旧引用，全部迁移到 fastjson2）
> - `historyInfo` 模块已整体删除
> - `BasicFilter` JUnit @Order Bug 已修复（改为 Spring @Order）
> - `Tag.category_id` Integer → Long 类型修复
> - `MomentController` 旧字段（type/isPublic）已适配新结构
> - `UserServiceImpl` 注册欢迎动态已适配新 Moment 实体

### 5. 数据库表与实体不同步

- `docs/sql/fix_id_type.sql`：所有表 ID 从 INT → BIGINT 的迁移脚本已写好但未执行
- `docs/sql/fix_is_del.sql`：`is_del` 逻辑删除列的脚本已写好但未执行
- `access_log` 表缺少 CREATE TABLE 语句
- 旧废弃表残留（8 张）：`history_info`, `sort`, `label`, `tree_hole`, `wei_yan`, `comment_old`, `resource`, `resource_path`

### 6. 行为模块待完善

- 行为统计聚合接口未完成
- 计数操作未加乐观锁（高并发丢计数风险）
- 行为模块单元测试缺失

### 7. OpenAPI 文档覆盖

| 指标 | 数值 |
|------|------|
| Controller 总数 | 30 |
| 有 @Operation 的 Controller | 13（43%） |
| 有 @Tag 的 Controller | 19（63%） |
| 无注解的 Controller | 17（57%） |

**已补全 OpenAPI 的模块：** article, behavior, category, comment, danmaku, sysconfig, user, webInfo, weblinks
**未补全的模块：** access, family, im, moment, tag
