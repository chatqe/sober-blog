## 二、重构断点

### 1. Service 层缺失

- ~~`weblinks` 模块：6 个 Controller（Weblinks/Collect/Music/Picture/Qiniu/ResourceAggregation）~~ **已修复**（2026-06-22）
  - Collect/Music/Picture/Qiniu/ResourceAggregation 已迁移至 `file` 模块
  - WeblinksController 已接入新建的 `WeblinksService` + `WeblinksConvert`

### 2. Controller 缺失

- ~~`sysdict`：字典表管理没有 Controller 暴露接口~~ **已修复**（2026-06-22）
  - Admin Controller：分页查询、新增、更新、批量删除（类型+数据）
  - Web Controller：按 typeCode 查询、批量查询、代码值转标签、Redis 缓存
- ~~`family`：仅有 Admin Controller，缺 Web Controller~~ **已修复**（2026-06-23）
  - Admin FamilyController → `AdminFamilyController`（分页、CRUD、点赞防重、Redis 缓存）
  - 新增 `FamilyWebController`（公开查询）
- ~~`category`：仅有 Web Controller，缺 Admin 管理~~ **已修复**（2026-06-23）
  - CategoryTagController → `AdminCategoryController`（分页、CRUD、批量排序）
  - 新增 `CategoryWebController` + `CategorySubscribeController`
- ~~`tag`：仅有 Web Controller，缺 Admin 管理~~ **已修复**（2026-06-23）
  - TagController → `AdminTagController`（分页、CRUD、批量排序）
  - 新增 `TagWebController`
- ~~`system`：空目录，待决定用途~~

- ~~`moment`：仅有 Web Controller，缺 Admin 管理~~ **已修复**（2026-06-25）
  - 新增 `AdminMomentController`（分页查询、CRUD、批量删除、审核）
  - 新增 `MomentService` admin CRUD 方法（pageList/getDetail/save/update/delete/batchDelete/audit）
  - 新增 DTO/VO 分层（MomentPageQueryDTO/MomentSaveReqDTO/MomentDetailVO/MomentListVO）

- `im` 模块用 `entity/` 而其他模块统一用 `domain/pojo/`
- `im` 模块 Controller 用 `http/controller/` 而非标准 `controller/web/admin/`
