## 二、重构断点

### 1. Service 层缺失

- `weblinks` 模块：6 个 Controller（Weblinks/Collect/Music/Picture/Qiniu/ResourceAggregation）全部没有 Service，违反分层规范

### 2. Controller 缺失

- `historyInfo`：有 Service 和 Entity，但没有 Controller
- `sysdict`：字典表管理没有 Controller 暴露接口
- `system`：空目录

### 3. Entity 命名不一致

- `im` 模块用 `entity/` 而其他模块统一用 `domain/pojo/`
- `im` 模块 Controller 用 `http/controller/` 而非标准 `controller/web/admin/`

### 4. 旧代码残留

- `PoetryCache` 已废弃（被 QingSiCache 替代），但 17 个文件中有大量注释掉的 PoetryCache 引用
- `ResourceCheckAspect` 是空壳实现
- `framework/plugin/` 空目录
- `BasicFilter.java` 错误引入了 JUnit 的 `@Order` 注解（Bug）
- `FileVO.java` 误放在 `common/` 根包下

### 5. fastjson 新旧包名混用

- 5 个文件仍用 `com.alibaba.fastjson.JSON`（旧），其余用 `fastjson2`

### 6. 数据库表与实体不同步

- `docs/sql/fix_id_type.sql`：所有表 ID 从 INT → BIGINT 的迁移脚本已写好但未执行
- `docs/sql/fix_is_del.sql`：`is_del` 逻辑删除列的脚本已写好但未执行
- `access_log` 表缺少 CREATE TABLE 语句

### 7. 行为模块待完善

- 行为统计聚合接口未完成
- 计数操作未加乐观锁（高并发丢计数风险）
- 行为模块单元测试缺失
