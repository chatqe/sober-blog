# qs-blog 功能接口梳理文档

## 一、内容域 (Content)

### 1. 文章 (article)

- web 端 (w)

  ： 

  1. 分页列表查询（带模糊检索，含关联分类 / 标签）
  2. 文章详情
  3. 推荐列表（热门 / 随机）→ 热门文章列表进行计分权重排序 → Redis 缓存

- admin 端 (a)

  ： 

  1. 新增文章
  2. 编辑文章
  3. 文章置顶 / 取消置顶（密码校验，前端判定）
  4. 查看状态变更 → 是否公开
  5. 文章审核（审核状态变更）
  6. 删除文章

- **模块总计**：web 端 3 个，admin 端 6 个 → 共 **9 个**

------

### 2. 分类 (category)

- web 端 (w)

  ： 

  1. 导航栏分类列表
  2. 根据分类获取文章分页列表

- admin 端 (a)

  ： 

  1. 分类列表
  2. 查询分类
  3. 新增分类
  4. 编辑分类
  5. 删除分类

- **模块总计**：web 端 2 个，admin 端 5 个 → 共 **7 个**

------

### 3. 标签 (tag)

- web 端 (w)

  ： 

  1. 首页标签云展示（含使用数量）
  2. 根据标签获取文章列表

- admin 端 (a)

  ： 

  1. 标签列表
  2. 标签搜索
  3. 标签新增
  4. 标签修改
  5. 标签删除

- **模块总计**：web 端 2 个，admin 端 5 个 → 共 **7 个**

------

### 4. 动态 (memont)

- web 端 (w)

  ： 

  1. 动态列表展示
  2. 删除自己的动态
  3. 新增动态
  4. 动态权限修改（是否可评论）

- admin 端 (a)

  ： 

  1. 动态列表
  2. 删除他人动态（违规处置）
  3. 动态详情
  4. 动态权限修改（是否可评论）

- **模块总计**：web 端 4 个，admin 端 4 个 → 共 **8 个**

------

### 5. 树洞 (danmaku)

- web 端 (w)

  ： 

  1. 弹幕列表
  2. 弹幕新增

- admin 端 (a)

  ： 

  1. 弹幕列表
  2. 弹幕删除
  3. 树洞审核 / 删除（敏感词过滤）待定

- **模块总计**：web 端 2 个，admin 端 3 个 → 共 **5 个**

------

### 6. 友链 (weblinks)

- web 端 (w)

  ： 

  1. 友链列表展示（状态为已审核）
  2. 新增（申请）

- admin 端 (a)

  ： 

  1. 友链列表（全量）
  2. 更新
  3. 删除
  4. 新增

- **模块总计**：web 端 2 个，admin 端 4 个 → 共 **6 个**

------

**内容域接口汇总**：

- web 端：3 + 2 + 2 + 4 + 2 + 2 = **15 个**
- admin 端：6 + 5 + 5 + 4 + 3 + 4 = **27 个**
- 内容域总计：**42 个**

  ： 

  1. 新增浏览行为

- admin 端 (a)

  1. UV 独立访客浏览量

- **模块总计**：web 端 3 个，admin 端 3 个 → 共 **6 个**

------

### 7. 行为基础设施 (Behavior)

- BehaviorState 当前状态

  ： 

  - web 端 (w)：1 个
  - admin 端 (a)：1 个

- BehaviorLog 行为流水

  ： 

  - web 端 (w)：1 个
  - admin 端 (a)：1 个（总行为流水列表，支持按用户 / 行为主体 / 内容 / 行为 / 时间 / 条件查询）

- BehaviorCnt 聚合计数

  ： 

  - web 端 (w)：1 个
  - admin 端 (a)：2 个（查询、输入文本）

- **模块总计**：web 端 3 个，admin 端 4 个 → 共 **7 个**

------

## 五、系统运维域 ()

### 1. 系统配置 (webinfo)

- web 端 (w)

  ： 

  1. 获取首页配置数据（首页横幅、网站 logo、网站名称、网站简介、底部页脚说明）
  2. github 仓库地址、邮箱、社交账号
  3. 查询网站背景图列表 → 做缓存
  4. 三方 Api 地理位置信息展示
  5. 获取完整站点配置信息
  6. 文件服务器选择

- admin 端 (a)

  ： 

  1. 相关信息新增
  2. 修改
  3. 删除

- **模块总计**：web 端 6 个，admin 端 3 个 → 共 **9 个**

------

### 2. 字典 (sysdict)

- web 端 (w)

  ： 

  1. 根据字典类型获取字典数据列表（只读，下拉选项用）

- admin 端 (a)

  ： 

  1. 分类列表

  3. 修改分类

  6. 新增标签
  7. 修改标签
  8. 删除标签

- **模块总计**：web 端 1 个，admin 端 8 个 → 共 **9 个**

------
